# Style panel prototype

Interactive prototype of a style panel for a visual website builder, made for my product design portfolio.

**Live:** https://denmatko.github.io/style-bar-prototype/

**Component workbench:** https://denmatko.github.io/style-bar-prototype/workbench/ (every panel control in every state)

Select an element on the canvas or in the Elements Tree, then change its styles in the left panel. Try breakpoints, states, variables, the colour picker, Raw CSS and undo/redo. Best viewed on desktop.

Built as a single HTML file (React 18 + htm from a CDN), no build step.
